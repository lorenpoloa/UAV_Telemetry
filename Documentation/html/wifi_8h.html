Descripción detallada

Interfaz pública del driver WiFi basado en comandos AT.

Autor
Lorenzo
Fecha
25 abr 2026

El módulo encapsula las operaciones de red necesarias para el proyecto: conexión al punto de acceso, transporte TCP, envío HTTP y publicación MQTT. La API mantiene una interfaz de alto nivel para que las tareas de FreeRTOS no dependan del formato concreto de los comandos AT ni de las respuestas del módulo WiFi.

Publica un payload en un topic MQTT.

Parámetros
[in]topicTopic MQTT de destino.
[in]payloadContenido que se publicará.
[in]qosNivel QoS solicitado para la publicación.
[in]retainFlag retain enviado al broker.
Devuelve
WIFI_OK si el módulo acepta la publicación.
WIFI_NOT_CONNECTED si no existe sesión MQTT activa.
WIFI_ERROR si el comando de publicación falla.

La función permite a las tareas publicar telemetría sin conocer el comando AT concreto ni la sintaxis interna del módulo WiFi.

Parámetros
[in]topicTopic MQTT de destino.
[in]payloadCadena que se publica como contenido del mensaje.
[in]qosNivel QoS solicitado al módulo WiFi.
[in]retainFlag retain del mensaje MQTT.
Valores devueltos
WIFI_OKPublicación aceptada por el módulo.
WIFI_ERRORError devuelto por el módulo o fallo de transmisión.
WIFI_TIMEOUTNo hubo confirmación dentro del tiempo límite.

Si la publicación falla, el estado se degrada a WIFI_CONNECTED porque la red puede seguir activa aunque la sesión MQTT haya quedado inválida. Esta decisión permite que la capa superior intente reconstruir solo MQTT antes de reiniciar toda la conexión WiFi.

◆ WIFI_Reconnect()

wifi_status_t WIFI_Reconnect ( void )

Ejecuta la secuencia de reconexión WiFi definida por el driver.

Reconstruye la conexión WiFi y MQTT usando la configuración almacenada.

Devuelve
WIFI_OK si se recupera la conectividad.
WIFI_ERROR si la reconexión falla.

Centralizar la reconexión evita que varias tareas intenten recuperar el módem con secuencias distintas.

Ejecuta la secuencia de reconexión WiFi definida por el driver.

Valores devueltos
WIFI_OKReconexión completada hasta MQTT.
WIFI_ERRORNo se pudo restaurar WiFi o MQTT.

La rutina distingue entre pérdida total de WiFi y pérdida solo de MQTT para no reiniciar más capas de las necesarias. Esto reduce tiempo de recuperación y evita cortes innecesarios cuando el punto de acceso sigue disponible.
