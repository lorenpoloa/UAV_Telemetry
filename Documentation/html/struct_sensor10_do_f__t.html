Descripción detallada

Conjunto completo de medidas calculadas por el módulo 10DoF.

La estructura agrupa todas las magnitudes derivadas de una lectura para que la aplicación pueda mover una muestra coherente entre tareas. Las unidades se expresan en formato físico de alto nivel y no en cuentas ADC o registros del sensor.
