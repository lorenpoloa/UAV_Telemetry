Este archivo separa los estados y códigos de retorno de la API principal para que puedan reutilizarse en distintos módulos sin introducir dependencias circulares con el driver WiFi completo.

Documentación de enumeraciones

◆ wifi_state_t

enum wifi_state_t

Estado lógico de la conexión WiFi/MQTT.

El estado se expone a la aplicación para decidir si debe reintentar conexión, publicar telemetría o esperar a que el módulo alcance una fase superior.

Valores de enumeraciones
WIFI_DISCONNECTED 

El módulo no está asociado a una red WiFi.

WIFI_CONNECTED 

El módulo está asociado al punto de acceso.

WIFI_GOT_IP 

El módulo dispone de dirección IP.

WIFI_MQTT_CONNECTED 

La sesión MQTT está establecida.

◆ wifi_status_t

enum wifi_status_t

Códigos de resultado de las operaciones WiFi.

Permiten a las tareas de FreeRTOS diferenciar entre fallos recuperables, ausencia de conexión y recursos ocupados, manteniendo una política de recuperación desacoplada de los comandos AT concretos.

Valores de enumeraciones
WIFI_OK 

Operación completada correctamente.

WIFI_ERROR 

Error genérico durante la operación.

WIFI_TIMEOUT 

No se recibió respuesta dentro del tiempo esperado.

WIFI_NOT_CONNECTED 

La operación requiere una conexión que todavía no existe.

WIFI_BUSY 

El módulo está ocupado o no puede aceptar una nueva operación.
