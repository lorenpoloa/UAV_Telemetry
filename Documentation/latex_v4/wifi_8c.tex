\doxysubsection{Descripción detallada}
Driver Wi\+Fi/\+\+MQTT basado en comandos AT con RX DMA circular y TX DMA sincronizado. 

La arquitectura separa recepción y transmisión en dos canales de hardware:\+ recepción DMA circular permanente para no perder respuestas asíncronas del módulo Wi\+Fi, y transmisión DMA sincronizada mediante semáforo para que las tareas Free\+RTOS esperen sin ocupar CPU durante el envío físico por UART.
