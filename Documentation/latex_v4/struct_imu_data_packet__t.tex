\doxysubsection{Descripción detallada}
Paquete normalizado con las magnitudes procedentes de la IMU. 

Agrupa acelerómetro, giróscopo y magnetómetro en un único bloque para que la tarea de publicación pueda tratar la lectura inercial como una muestra atómica. El timestamp permite ordenar las muestras aunque se reciban con distinta latencia dentro del pipeline.
