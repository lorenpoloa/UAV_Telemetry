\doxysubsection{Descripción detallada}
Paquete normalizado con la posición procedente del receptor GPS. 

Se separa del paquete IMU porque la frecuencia y la validez de las tramas GPS son independientes de las lecturas inerciales. El flag de actualización evita publicar repetidamente una posición antigua cuando no llega una nueva trama válida.
