\doxysubsection{Descripción detallada}
Interfaz pública del módulo de adquisición del sensor 10DoF. 

Este driver concentra la inicialización, recuperación y lectura de las magnitudes inerciales, magnéticas y ambientales usadas por el sistema. La API devuelve valores ya convertidos a unidades de aplicación para que las tareas de Free\+RTOS y la capa de telemetría no dependan de registros ni escalas internas de cada sensor.
