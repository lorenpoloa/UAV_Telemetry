\doxysubsection{Descripción detallada}
Paquete normalizado con las magnitudes ambientales. 

Mantiene juntas las variables ambientales calculadas por el módulo 10DoF para evitar que temperatura, presión y rumbo pertenezcan a instantes distintos al ser enviados por la capa de comunicación.
