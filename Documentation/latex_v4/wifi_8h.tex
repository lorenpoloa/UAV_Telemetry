\doxysubsection{Descripción detallada}
Interfaz pública del driver Wi\+Fi basado en comandos AT. 

\begin{DoxyAuthor}{Autor}
Lorenzo 
\end{DoxyAuthor}
\begin{DoxyDate}{Fecha}
25 abr 2026
\end{DoxyDate}
El módulo encapsula las operaciones de red necesarias para el proyecto:\+ conexión al punto de acceso, transporte TCP, envío HTTP y publicación MQTT. La API mantiene una interfaz de alto nivel para que las tareas de Free\+RTOS no dependan del formato concreto de los comandos AT ni de las respuestas del módulo Wi\+Fi.
