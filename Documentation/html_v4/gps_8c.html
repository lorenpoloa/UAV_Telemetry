Descripción detallada

Driver no bloqueante para recepción y procesado de tramas NMEA GPS.

Autor
Lorenzo
Fecha
13 may 2026

El módulo recibe bytes por interrupción UART y los desacopla del parser usando un búfer circular. Esta arquitectura evita realizar trabajo pesado dentro de la ISR y permite que el procesado de sentencias NMEA se ejecute desde una tarea o bucle principal con menor impacto temporal.

void gps_parse_gga ( char * nmea)
static

Decodifica una sentencia GGA y actualiza posición, fix, satélites y altitud.

Parámetros
[in,out]nmeaSentencia NMEA modificable.

Se usa GGA porque concentra la información de calidad de fix y altitud. La sentencia se tokeniza in situ para evitar buffers adicionales en RAM.

Atención
strtok() modifica la cadena recibida; no se debe reutilizar la sentencia original después de llamar a esta función.
