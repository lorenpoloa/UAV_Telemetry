Descripción detallada

Interfaz pública del módulo de adquisición del sensor 10DoF.

Este driver concentra la inicialización, recuperación y lectura de las magnitudes inerciales, magnéticas y ambientales usadas por el sistema. La API devuelve valores ya convertidos a unidades de aplicación para que las tareas de FreeRTOS y la capa de telemetría no dependan de registros ni escalas internas de cada sensor.

Intenta recuperar el bus I2C generando pulsos manuales en SCL.

Esta operación está pensada para liberar el bus cuando un dispositivo mantiene líneas bloqueadas tras una transacción incompleta o un reinicio inesperado.

Ejecuta una recuperación manual del bus I2C usado por el módulo.

Algunos esclavos I2C pueden dejar SDA retenida tras un reset o una transferencia interrumpida. La recuperación conmuta temporalmente SCL/SDA como GPIO para liberar el bus antes de reinicializar el periférico I2C.

◆ Sensor10DoF_Init()

SensorStatus_t Sensor10DoF_Init ( void )

Inicializa los sensores y prepara el bus de comunicación.

Inicializa todos los sensores del módulo 10DoF.

Devuelve
SENSOR_OK si todos los dispositivos quedan listos para lectura.
SENSOR_ERROR si algún dispositivo no responde o no queda configurado.
SENSOR_TIMEOUT si el bus no responde dentro del tiempo esperado.

Debe llamarse antes de solicitar lecturas para asegurar que las escalas, registros y compensaciones iniciales están configuradas de forma coherente.

Inicializa los sensores y prepara el bus de comunicación.

Valores devueltos
SENSOR_OKTodos los dispositivos respondieron y quedaron configurados.
SENSOR_ERRORAlgún dispositivo no respondió, no pudo configurarse o falló la calibración.

La función verifica primero la presencia de todos los esclavos I2C antes de configurar registros. Esto permite detectar fallos de cableado o bloqueo de bus antes de producir lecturas parciales incoherentes.

◆ Sensor10DoF_Read()

SensorStatus_t Sensor10DoF_Read ( Sensor10DoF_t * d)

Lee una muestra completa del módulo 10DoF.

Lee todos los sensores y rellena una muestra 10DoF completa.

Parámetros
[out]dataEstructura donde se almacenan las magnitudes convertidas.
Devuelve
SENSOR_OK si la lectura se completa correctamente.
SENSOR_ERROR si alguna magnitud no puede actualizarse.
SENSOR_TIMEOUT si un dispositivo no responde a tiempo.
SENSOR_BUSY si el módulo no puede atender la lectura en ese instante.
Precondición
data debe apuntar a una estructura válida.

La función entrega una muestra agregada para reducir el acoplamiento entre las tareas consumidoras y los distintos sensores físicos que forman el módulo.

Lee una muestra completa del módulo 10DoF.

Parámetros
[out]dEstructura de destino con aceleración, orientación, campo magnético, velocidad angular, temperatura, presión y altitud.
Valores devueltos
SENSOR_OKMuestra actualizada correctamente.
SENSOR_ERRORError de argumento, comunicación o compensación inválida.

La función entrega magnitudes ya convertidas para aislar al resto del proyecto de escalas de registros. También calcula roll, pitch y heading compensado por inclinación para que la interfaz pueda consumir directamente valores físicos.

Precondición
Sensor10DoF_Init() debe haberse ejecutado correctamente.

Recupera el bus I2C y reinicializa el módulo 10DoF.

Se utiliza como mecanismo de recuperación cuando la secuencia de lectura queda en un estado no fiable y conviene volver a una condición conocida.

Se proporciona como rutina de recuperación ante errores de comunicación. La función intenta dejar el bus y los sensores en un estado operativo sin exponer a las capas superiores los detalles eléctricos de recuperación.
