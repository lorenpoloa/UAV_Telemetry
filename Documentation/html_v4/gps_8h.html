Descripción detallada

Interfaz pública del driver GPS basado en recepción UART.

Autor
Lorenzo
Fecha
13 may 2026

El módulo encapsula la recepción y el procesado de tramas NMEA para ofrecer al resto del sistema una estructura de datos estable. La separación entre callback UART, procesado y consulta de datos permite integrarlo en FreeRTOS sin bloquear las tareas de adquisición o comunicación.

Documentación de «define»

◆ GPS_RX_BUFFER_SIZE

#define GPS_RX_BUFFER_SIZE   512

Tamaño del buffer circular usado para desacoplar la UART del parser.

Se dimensiona por encima de una única sentencia NMEA para absorber ráfagas o pequeñas latencias de planificación sin perder caracteres.

◆ GPS_SENTENCE_MAX_LENGTH

#define GPS_SENTENCE_MAX_LENGTH   128

Longitud máxima esperada para una sentencia NMEA completa.

Limita el almacenamiento temporal de una trama individual y protege al parser frente a entradas corruptas o sin terminador.

Reinicia la recepción UART del GPS.

Rearma manualmente la recepción UART del GPS.

Se expone para recuperar la recepción tras errores o condiciones de parada sin reinicializar toda la aplicación.

Reinicia la recepción UART del GPS.

Esta función permite recuperar la escucha si una condición externa cancela o interrumpe la recepción por interrupción. Se reutiliza el byte interno para mantener encapsulado el estado de recepción.
